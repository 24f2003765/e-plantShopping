# Paradise Nursery Shopping Application (e-plantShopping)

**Project name:** Paradise Nursery Shopping Application  
**Course:** IBM Developing Front-End Apps with React — Final Project  
**Author:** 24f2003765@ds.study.iitm.ac.in

A React and Redux Toolkit shopping cart app for Paradise Nursery, an online plant shop. Users browse categorized houseplants, add items to a cart, adjust quantities, and view totals.

## Features

- Landing page with company branding and Get Started navigation
- Product listing with plants grouped by category
- Redux-managed shopping cart with dynamic navbar badge
- Cart page with quantity controls, delete, continue shopping, and checkout placeholder

## Technologies

- React 18
- Redux Toolkit & React-Redux
- Vite

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically http://localhost:5173).
